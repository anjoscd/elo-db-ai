# Security policy

ELO runs locally and reads your source code and project knowledge. Its security promise:

- **No telemetry and no network** in the default build. Any feature that needs network access is opt-in, documented and off by default.
- **Data stays in the workspace** (`.elo/`). ELO never uploads code, prompts or memories.
- Hook output is **data, not instructions**: ELO marks the source of every injected block.

## Reporting a vulnerability

Please do not open a public issue. Use GitHub's private vulnerability reporting (Security → Report a vulnerability). We aim to answer within 7 days.
